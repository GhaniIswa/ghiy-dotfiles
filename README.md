# My custom script.
Simple script which is music play on terminal, and stream using youtube links. (probably more in the future)

### Dependencies:
- mpv
- yt-dlp
- fzf

why use this? well it's lighter than streaming music from your favorite browser.

and don't forget to run:
`sudo ln -s ~/.config/musicply/music /usr/local/bin/music`
